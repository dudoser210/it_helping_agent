# Техническое задание: IT Helping Agent

## 1. Назначение

Создать локальную мультиагентную систему первой линии поддержки для обработки русскоязычных заявок сотрудников по Wi-Fi, принтерам, доступам и программному обеспечению.

## 2. Пользователи и сценарии

- сотрудник создаёт заявку и получает безопасные шаги;
- инженер Helping получает классификацию, приоритет и причину эскалации;
- администратор наблюдает latency, ошибки, токены и доступность системы;
- преподаватель воспроизводит запуск и eval-набор на локальном ПК.

## 3. Функциональные требования

1. Принимать текст, employee ID, устройство, ОС и локацию через REST/UI/CLI.
2. Определять одну или несколько категорий и приоритет.
3. Вызывать релевантных специалистов параллельно.
4. Извлекать локальные runbook-фрагменты и ссылаться на источники.
5. Проверять результат независимым агентом политики и кодовым safety-gate.
6. Возвращать упорядоченные шаги, вопросы или эскалацию.
7. Хранить локальную историю заявок сотрудника в SQLite.
8. Экспортировать метрики, JSON-логи и OpenTelemetry-трейсы.
9. Иметь unit-тесты и воспроизводимый LLM eval-набор.

## 4. Нефункциональные требования

- локальный inference через Ollama/Qwen3.5;
- отсутствие исходящих cloud LLM вызовов;
- контейнер работает непривилегированным пользователем, без Linux capabilities, с read-only root FS;
- секреты и пароли не должны повторяться в ответе;
- p95 latency целево до 60 секунд на GPU; на CPU фиксируется отдельный baseline;
- все промпты, скиллы и база знаний версионируются как Markdown.

## 5. Критерии приёмки

- `docker compose up --build` запускает API и observability;
- `/health` видит модель Ollama;
- четыре базовых домена маршрутизируются корректно;
- unit-тесты проходят без Ollama;
- eval pass rate не ниже 0.75 на стартовом наборе;
- safety violation rate равен нулю;
- Grafana показывает обращения, latency, ошибки и токены; Jaeger показывает цепочку агентов.

## 6. Вне рамок v1

Автоматическое исполнение команд, реальная выдача прав, интеграция с AD/Entra/Jira/ServiceNow, speech-to-text, анализ вложений и production HA.
