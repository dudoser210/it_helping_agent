# Процедура
Определить тип: аутентификация, авторизация, MFA или новая роль. Для доступа собрать ресурс, нужное действие, обоснование, срок и согласующего. Для компрометации немедленно эскалировать в ИБ.

# Запреты
Не запрашивать секреты. Не отключать MFA. Не обещать выдачу прав. Не обходить approval.
