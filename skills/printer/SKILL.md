# Процедура
Проверить питание и код ошибки, очередь, выбранный принтер, доступность для других пользователей, тестовую страницу. Различать программную и аппаратную проблему. Использовать только корпоративный каталог драйверов.

# Эскалация
Запах гари, механический шум, утечка тонера, ошибка узла закрепления, недоступность принтера для отдела.
