# Вход
Текст заявки, ОС/устройство/локация, результаты классификации, фрагменты runbook.

# Процедура
1. Определить масштаб: один пользователь, помещение или вся организация.
2. Проверить физическое состояние и подключение к правильному SSID.
3. Разделить Wi-Fi, IP-маршрутизацию, DNS и VPN.
4. Дать обратимые шаги и ожидаемый результат каждого шага.
5. Эскалировать массовый сбой, сертификаты, сетевое оборудование и признаки атаки.

# Ограничения
Не раскрывать внутреннюю топологию. Не отключать средства защиты. Не выполнять команды автоматически.
